# 🧮 Calculadora Simples em Java

Uma aplicação de console desenvolvida em Java que realiza operações matemáticas básicas de forma direta e eficiente. Ideal como projeto introdutório para demonstrar domínio de estruturas fundamentais da linguagem.

## 📌 Sobre o projeto

Esta calculadora permite ao usuário escolher uma operação matemática e aplicar sobre dois números fornecidos via terminal.

Operações suportadas:

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão (com validação para evitar divisão por zero)

O objetivo deste projeto é reforçar conceitos essenciais como:
- Entrada de dados com `Scanner`
- Estruturas condicionais (`switch-case`)
- Validação de dados
- Organização de código em Java

---

## 🚀 Tecnologias utilizadas

- Java (JDK 8+)
- Paradigma orientado a objetos (estrutura básica)

---
